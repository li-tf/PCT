# 质子CT下一阶段研究计划

**更新日期：2026-08-03**

本文件只回答三个问题：研究目标是什么、当前冻结基线是什么、下一步按什么顺序
推进。阶段0--8的实验设计、执行结果、负结果和决策依据统一归档到
[`current_research_summary.md`](current_research_summary.md)，不再在计划文件中
重复维护。

## 1. 目标与基本原则

### 1.1 总目标

在已完成的二维理想测量、硅跟踪器、通量敏感性和首轮三维重建基础上，建立一套
物理口径明确、定量可信、能够扩展到真实探测器和三维场景的pCT重建方法。近期
重点不是继续堆叠算法复杂度，而是解决Stage 8中“数据链正确但材料恢复失败”的
三维系统问题。

需要继续回答的核心问题是：

1. 三维坐标、角度映射、有限圆柱求交和路径覆盖是否完全正确；
2. 首轮三维材料球误差中，系统实现、路径模型、采样覆盖和未充分收敛各占多少；
3. 二维冻结算法在真实位置/能量噪声和更低通量下的工作边界在哪里；
4. 可靠体素基线形成后，3D Gaussian等连续表示是否能在定量、分辨率或计算效率
   上提供可验证收益。

### 1.2 评价口径

- 单质子WEPL使用Stage 6B冻结的`g4_water_calibrated`射程模型；`bb78`只用于
  历史复现。
- 材料RSP以Stage 6A的200 MeV高统计虚拟MLIC结果为主口径；理论固定RSP保留
  为补充解释。
- 新数据在过滤和算法选择前按稳定质子身份划分为80%训练、10%验证和10%锁定
  测试；测试集只在方法与epoch冻结后打开一次。
- 同时报告图像RSP、固定验证/测试WEPL、空间分辨率、运行时间和资源占用；没有
  DoseActor时只报告通量，不换算为mGy。
- “流程PASS”和“性能PASS”分开判定。程序完整运行、算子伴随和数据有限性通过，
  不代表材料定量已经可信。

### 1.3 实施原则

1. 每次只改变一个主要因素，并保留配对对照；
2. 先用合成数据和小规模pilot验证上限，再运行全量数据；
3. 优先定位系统误差，不用更强正则化掩盖错误；
4. 负结果同样保留，并明确“不晋升”的原因；
5. 二维成熟代码保持冻结，三维代码继续位于独立工程`pct3d_reconstruction/`；
6. 大型ROOT、pairs和检查点放在`data/`或外部存储，代码侧只保留配置、QC和报告。

## 2. 当前基线

### 2.1 当前正式二维算法

当前可复用的最优二维配置为：

| 环节 | 冻结选择 |
|---|---|
| 配对与过滤 | primary-only配对；局部均值/标准差3σ过滤 |
| WEPL | `g4_water_calibrated` |
| 路径 | 均匀水Schulte MLP |
| 初值 | no-Hann MLP-DDB-FDK |
| 迭代 | GPU list-mode OS-SART，18子集，5 epoch |
| 松弛 | 初值0.25，衰减系数0.2 |
| 数据项 | 等权quadratic |
| 图像先验 | 固定Huber-TV，`β=0.0125` |
| 约束 | RSP非负、二维圆柱支撑域 |

在Stage 6B重新标定WEPL后，三种经典二维场景的代表结果为：

| 场景 | 核心结果 |
|---|---|
| S1：25根5 mm铝柱 | 水均值0.999733；铝相对MLIC误差−1.307% |
| S4：多材料 | 15 mm大柱MLIC-MAPE 0.2551%；全部非Air 0.4408% |
| S5：线对与斜边 | 平均fMTF50 0.5003 lp/mm；fMTF10 1.1733 lp/mm |

Stage 7证明四层连续硅hit相对理想参考面的影响较小，但0.2 mm位置误差与1%
出射能量噪声组合使RMSE增加42.73%。Stage 7B没有找到优于等权quadratic的
加权或Huber数据项。Stage 7C给出的推荐最低有效通量为25%，即
225 protons/mm²/projection；10%通量下冻结的5轮算法失稳。

### 2.2 Stage 8首轮三维基线

Stage 8已经完成360角度compact-3D数据处理、三维Schulte MLP、三线性8邻域
严格伴随算子、正则化筛选和80%训练集3 epoch重建。工程状态为
**PIPELINE PASS**，但性能状态为**PERFORMANCE FAIL**：

| 指标 | 首轮结果 |
|---|---:|
| 测试WEPL RMSE | 2.0146 mm |
| 水区RSP偏差 | −0.1247% |
| 模体RSP RMSE | 0.05330 |
| 10--14 mm非Air材料球MAPE | 37.03% |
| 6 mm铝球误差 | −29.71% |
| Air球重建RSP | 0.4587 |

水平台和WEPL有限且稳定，但材料对比严重低估，Stage 8尚不能作为可靠的三维
性能基线。当前二维最优算法仍是正式主基线。

## 3. 总体路线和优先级

| 顺序 | 工作 | 优先级 | 当前状态 | 启动/完成条件 |
|---:|---|---:|---|---|
| 1 | Stage 8三维系统诊断 | P0 | 立即执行 | 找到材料球严重低估和Air球残留的主要原因 |
| 2 | Stage 8受控修正与复算 | P0 | 等待诊断 | 合成闭环、坐标和覆盖检查全部通过后再全量运行 |
| 3 | Stage 8可靠体素基线冻结 | P0 | BLOCKED | 大材料球恢复达到可解释水平，测试纪律完整 |
| 4 | Stage 7真实噪声进一步研究 | P1 | 可并行做小规模分析 | 有独立能量响应或更可信数字化模型后再研究似然权重 |
| 5 | 低通量算法适配 | P2 | 暂缓 | 只针对25%以下通量重新选择epoch和正则化 |
| 6 | Stage 9：3D Gaussian可行性 | P2 | BLOCKED | 以通过验收的Stage 8体素结果作为同数据基线 |
| 7 | 显式最小二乘与停止准则 | P3 | 备选 | 需要更严格收敛解释时启动 |
| 8 | 多分辨率和算子工程 | P3 | 备选 | 诊断完成且计算成本成为主要瓶颈时启动 |

### 3.1 Stage 8诊断顺序

1. 用常数有限圆柱验证每条射线的理论线积分和角度不变性；
2. 用单个Air球、单个高RSP球和离轴球验证0°、90°及任意角坐标映射；
3. 绘制各材料球的路径数量、累计列权重和轴向覆盖，检查是否存在局部欠采样；
4. 核对scanner坐标到object坐标的(R_y(-\theta))关系，以及内部数组
   `(z,y,x)`与MHD `(x,y,z)`的转换；
5. 复核圆柱侧壁/端盖求交、外部Air扣除和内部Air球处理是否在同一坐标系；
6. 在不打开测试集、不改变物理模型的条件下继续训练若干epoch，估计未收敛贡献；
7. 只有系统检查通过后，才重新筛选三维正则化并执行正式确认。

### 3.2 Stage 9启动门槛

3D Gaussian首版只做“每次扫描独立优化”，不训练通用患者模型。启动前必须：

- Stage 8体素前投影、坐标和材料平台均通过验收；
- 固定同一训练/验证/测试质子与同一MLIC真值；
- 建立沿弯曲MLP对Gaussian RSP场积分的可微算子；
- 同时比较测试WEPL、材料MAPE、空间分辨率、速度和显存，而不是只比较视觉效果。

当前compact-3D数据足以回答单场景可行性，但不足以证明跨模体、跨能量和跨
探测器泛化。可靠体素基线形成之前，不启动Stage 9正式实验。
